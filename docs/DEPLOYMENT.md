# Standalone deployment

Follow the root README.md for this copy's current instructions. This version is for your own Cloudflare Workers account and uses Supabase authentication. It is not a Sites publication archive and must not be deployed through the Sites project workflow.

Create/configure your D1 database, apply remote migrations, build, then deploy the generated Worker configuration. The complete source ZIP must be built first; Cloudflare's static drag-and-drop uploader cannot deploy this app.
